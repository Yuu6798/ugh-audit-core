# Operator setup

The maintained [operator setup guide](ugh-instruction-audit/references/operator-setup.md)
and [server environment example](ugh-instruction-audit/templates/operator.env.example)
are included in the single-skill ZIP. They are for operators who explicitly choose
to deploy the separately licensed server; normal skill use needs an existing
invitation, the user's own Anthropic API key, and an external MCP client supporting
both secret HTTP headers. Model costs belong to the user; hosting belongs to the operator.
