# HA48 診断スナップショットの版管理

HA48 は既に開発・検証で使用した 48 回答である。以下は同じデータに対する
機械出力の回帰記録であり、新しい未見データによる独立評価でも、新しい人手
アノテーションでもない。人手評価列 `O` は全行で変更していない。

| 版 | CSV | ヒット合計 | 用途 |
|---|---|---|---|
| 修正前 v2 | `analysis/snapshots/ha48_regression_check.v2.csv` | 97/146 | 修正前ファイルの完全保存 |
| v3 legacy 診断 | `analysis/ha48_regression_check.csv` | 96/146 | 現行コードの回帰検出 |

修正前 CSV の SHA256 は
`556fd5a5d17706537c53eb13d892ddc7230159fc6a4c47e7489d7e0a8c63992f`。
版・コードのハッシュ・変更範囲は
`analysis/snapshots/ha48_snapshot_versions.json` に記録している。

2026-10-28 の修正で、通常の重なり照合経路にも既存の否定極性チェックを
適用した。再実行で変化を確認した行は `q012` のみだった。要件 1
「AIは意図しない自律的な振る舞いを見せる」に対し、既存の補助関数が認識する
局所的な否定表現を検出しないため、ヒット番号は `[0,1,2]` から `[0,2]` へ変化した。

| q012 の機械列 | 修正前 | 現行 |
|---|---|---|
| hits | 3 | 2 |
| C | 1.0 | 0.6667 |
| delta_e | 0.0026 | 0.0396 |
| quality_score | 4.9896 | 4.8414 |

他の機械列・行・人手 `O` は不変である。この差分は否定チェックの適用経路を
揃えた結果であり、q012 の意味上の正解を新たに人手確定したという主張ではない。
legacy の `C`・`ΔE` は診断値として扱う。要件の充足や公開可否をこの表だけで決めない。

`tests/test_ha48_regression.py` は修正前ファイルのバイト一致、宣言した 4 列のみの
差分、人手 `O` の不変性、現行コードと現行 CSV の一致を検査する。以前の論文統計は
当時の版に結び付けて参照し、現行の回帰テスト通過を統計的な再検証と呼ばない。
